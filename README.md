# Downrange — public legal pages

Public, GitHub Pages-hosted pages for the [Downrange](https://github.com/Shaux/Downrange)
Android app. Separate from the app's own (private) repo on purpose — this is
the one thing that has to be at a public URL (Google Play requires a live
public privacy policy link), so it's the only thing that's public.

- **Privacy policy** — `index.html`, served at this repo's Pages URL once
  Pages is turned on (Settings → Pages → Deploy from a branch → `main` → `/root`).

Edit `index.html` directly and push — GitHub Pages redeploys automatically.
